# Glyphr by Yeezik

Real-time image and video effects in the browser: ASCII, Dithering, Dots, VHS, Halftone, Pixel Sort, Glitch, CRT and Threshold.

- Drop a photo or video, pick an effect, tune it live
- Stack effects as layers, compare before / after, undo / redo
- Built-in and custom presets
- Export PNG, JPG, WebP, video (MP4 / WebM) and ASCII text, up to 8K

Everything runs locally on your device with WebGL2. Files are never uploaded.

Live: https://yeezikdev.github.io/glyphr/
